## 👨‍💻 Sobre mim

Sou **Desenvolvedor Full Stack**, com foco em **backend Java (Spring Boot)** e **frontend moderno com React.js**.  
Tenho experiência no desenvolvimento de aplicações web completas, desde a modelagem de banco de dados até a entrega de interfaces responsivas e bem estruturadas.

Atualmente, estou aprofundando meus conhecimentos em **Cloud Computing (AWS)**, com foco em boas práticas de arquitetura, escalabilidade e serviços gerenciados.

Busco oportunidades onde eu possa evoluir tecnicamente, contribuir com soluções de impacto e atuar em times colaborativos.
